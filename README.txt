ANKIT PRAJAPATI — PREMIUM PORTFOLIO
===================================

This is a lightweight, custom-built portfolio designed for PHP-compatible shared hosting.
It uses plain HTML + CSS + JavaScript. No Node.js or framework is required.

FILES
-----
index.html                 Main portfolio
projects.html              All projects
project-passport.html      Passport Photo Maker case study
project-homeguard.html     UP Home Guard Exam 2026 case study
project-digital.html       Digital Solutions case study
resume.html                Printable resume page
assets/style.css           Complete UI styles
assets/script.js           Navigation, smooth scroll and contact-mail behavior
resume.pdf                 Starter resume PDF

IMPORTANT: PERSONAL LINKS
-------------------------
Before publishing, replace these placeholders in index.html and resume.html:

YOUR_EMAIL@example.com
YOUR_WHATSAPP_NUMBER
https://www.linkedin.com/
https://github.com/

Also replace the project demo placeholders with the real URLs when available.

HOSTING
-------
For 42web/InfinityFree:
1. Upload all files/folders inside this package to your public_html/htdocs folder.
2. Keep index.html in the root.
3. Open your domain.
4. Test every navigation item on mobile.
5. After your real LinkedIn/GitHub/project URLs are ready, replace the placeholders.

CONTACT FORM
------------
The form uses mailto, so it opens the visitor's email application. It does not store submissions.
If you later want server-side email delivery, add a PHP mail/API endpoint.

RESUME
------
resume.html has a Print / Save PDF button. resume.pdf is included as a starter file.
Update the PDF and the HTML resume after finalizing your professional contact links.

HONEST PORTFOLIO RULE
---------------------
Do not add fake employment, fake clients, fake project results, fake GitHub repositories,
or fake live-demo URLs. Replace placeholders only with real links.

DESIGN
------
Dark premium UI, responsive mobile navigation, smooth scrolling, subtle CSS motion,
project case-study pages, education, certifications, experience, contact and SEO metadata.
